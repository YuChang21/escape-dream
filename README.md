# escape-dream
# 逃離夢境

《逃離夢境》是一款使用 HTML、CSS 與 JavaScript 製作的 2D 網頁小遊戲，
玩法類似小朋友下樓梯。

玩家需要控制穿著睡衣的小孩，在夢境中的平台持續向下移動，
避開尖刺與危險平台，並利用不同道具取得更高分數。

## 操作方式

- ← / A：向左移動
- → / D：向右移動
- P：暫停 / 繼續遊戲

## 道具

- ❤️ 愛心泡泡：恢復 1 點生命值，最多 3 顆心
- ⭐ 金色星星：10 秒內每秒得分 ×2
- 🪶 風之羽毛：10 秒內移動速度 +50%

## 遊戲特色

- 普通平台
- 尖刺平台
- 移動平台
- 碎裂平台
- 隨時間提升遊戲速度
- 時間計分系統
- 道具 Buff 系統
- 最高分紀錄
- 夢境風格介面與音效

## 遊玩方式

進入 GitHub Pages 網站即可直接遊玩。
